# Blackjack-EducationalApplication
This repository hold files for a Blackjack Educational Application. This application allows users to learn a basic skill set to play blackjack. User is given three pages: a learn page, settings page, and a play page.

# Learn Page
This page teaches the user about the rules our blackjack application has by default. After the user learns these rules, they can play around with the settings. Towards the end of the learn page the user gets tested on a subject of rules, and then the user can make basic hits and stands.
